# Chop & Join — source data transcription

This document transcribes two sets of handwritten/printed source material photographed for the
Chop & Join job order feature: (1) six real job pairs — a sales invoice paired with its matching
Chop & Join job requisition form — and (2) a set of handwritten pricing-formula notes.

**Status: raw transcription, not verified against the app or fully cross-checked against every
receipt total.** Numbers are transcribed as written, including apparent inconsistencies. Anywhere
the source is ambiguous, illegible, or internally inconsistent, that is called out explicitly
rather than silently resolved — do not treat this document as ground truth without review.

## Part 2 — Pricing formulas (handwritten notes)

Transcribed as written. `L` = length (in), `W` = width (in), `H` = height (aquarium only, in),
`FW` = frame width (in). "Price (input)" means a price value entered/selected by the user for that
component (e.g. the chosen moulding's or material's rate); "Framing Price (Poly)" / "Price (Wood)"
are the per-unit rates for polystyrene vs. wood moulding specifically.

### Standard ("formula") framing

**Polystyrene moulding:**
```
L × W × Price (input)
L + W × Framing Price (Poly)
```

**Wood moulding:**
```
L × W × Price (input)
(L + W + FW) / 3 × Price (Wood)
```

> Note: the wood formula divides `(L + W + FW)` by 3, while the poly formula has no such division —
> transcribed exactly as written on the source page; this asymmetry is in the original notes, not
> an error introduced here.

### Aquarium-type framing

**Polystyrene moulding:**
```
L × W × Price (input)
L + W + 4 × Framing Price (Poly)
```

**Wood moulding:**
```
L × W × Price (input)
(L + W + 4 + FW) / 3 × Price (Wood)
```

### Chop & Join formula (separate section, appears to be the markup/labor formula applied on top of or instead of the plain framing formula above)

**Polystyrene:**
```
(L + W) × C&J Price (Poly)
```

**Wood:**
```
(L + W + FW) / 3 × Price × 20% (Wood)
```

### Aquarium type — Chop & Join variant

**Polystyrene:**
```
(L + W + 4) × Framing Price (Poly)
   less 30%
```

**Wood:**
```
(L + W + 4 + FW) / 3 × Price (Wood)
   less 30%
```

### Octagon type — Chop & Join variant

**Polystyrene:**
```
(L + W) × Framing Price (Poly)
   less 30%
```

**Wood:**
```
(L + W + FW) / 3 × Price (Wood)
   less 10%
```

> ⚠️ Note the asymmetry: Aquarium wood and Aquarium poly both show "less 30%," but Octagon shows
> "less 30%" for poly and **"less 10%"** for wood — transcribed exactly as written; this is not a
> copy error on my part, double-check against the original notes since a 10%/30% mismatch between
> two adjacent formulas is exactly the kind of thing worth confirming with whoever wrote them down.

### Octagon type — plain framing (separate from the Chop & Join variant above)

**Polystyrene:**
```
L × W × Price (input)
L + W × Framing Price (Poly)
```

**Wood:**
```
L × W × Price (input)
(L + W + FW) / 3 × Price (Wood)
```

### Glass cut

**Single glass:**
```
L × W × 0.35   (if either dimension is 15″ or more)
L × W × 0.25   (if both dimensions are below 15″)
```

**Double glass:** same size-tiered rule, each multiplied by 2:
```
L × W × 0.35 × 2   (15″ and up)
L × W × 0.25 × 2   (below 15″)
```

**Acrylic glass:**
```
L × W × 2.50
```

**Non-glare glass:**
```
L × W × 1.5
```

**Octagon glass:**
```
L × W × 0.40
```

### Extra services

```
L × W × Price (input)
```

### Matt cut

**Store-supplied board:**
```
L × W × Price (input) × 20%
```

**Customer-supplied board:**
```
(L + W) × Price (input)
```

### Backing / board cuts

**Sintra board:**
```
L × W × 0.45
```

**Foam board:**
```
L × W   (no rate multiplier shown — likely a flat per-sq-in/sq-ft rate applied separately, or the
         rate was left blank/illegible on the source page)
```

**Plywood:**
```
L × W × 0.16   (1/8″ thickness)
L × W × 0.32   (3/16″ thickness)
```

**MDF:**
```
L × W × 0.12
```

**Plywood (marine grade):**
```
L × W × 0.45
```

### Hardware

**Flexipoints:**
```
(numerator + denominator) × 2 × 1.50
```
(i.e. for a fraction like "4/8", compute `(4 + 8) × 2 × 1.50`)

**Multipoints:**
```
(numerator + denominator) × 2 × 8
```

**L-support, Small:**
```
4 × 8   (fixed formula, not price-per-unit — appears to be a fixed quantity/dimension pair rather
         than a price calculation; transcribed as written)
```

**L-support, Big:**
```
4 × 16
```

> ⚠️ The L-support lines read as plain dimension pairs (4×8, 4×16) rather than price formulas like
> everything else on this page — they may represent a fixed unit count (e.g. "4 pieces, 8-inch
> size" vs "4 pieces, 16-inch size") rather than a computation. This matches the prototype's own
> `back.lsup` structure, which stores `size: 'Small'|'Big'` as a fixed category rather than a
> computed value — so treat these two lines as **hardware size labels**, not formulas, when
> implementing.

## Cross-check notes (what I verified vs. could not verify)

- **Front + Side + Top subtotal in the aquarium worked example** (350 + 770 + 192.50 = 1,312.50)
  arithmetically checks out exactly against the source's own subtotal — this part of the formula
  is confirmed self-consistent.
- **The wood-moulding "add base" rate (66) does not match the "Price (Wood)" label pattern used
  elsewhere** on the page (other wood examples use round supplier price points like 26.00, 53.50,
  60.00 from the actual receipts) — flagging as worth confirming, not correcting silently.
- **I did not attempt to reverse-derive the Chop & Join wood/poly formulas against the six job
  receipts above**, because the receipts' line amounts already include the shop's actual selling
  price and disc-rate math baked in (e.g. Job 1's wood moulding line shows a "20" in the Disc Rate
  column with the Amount already net of that discount), and the handwritten formula notes don't
  specify at what point a discount is applied relative to the L/W/FW formula. Attempting to
  back-solve without that piece would have produced a plausible-looking but unconfirmed number, so
  I left the two data sets side by side rather than force a reconciliation. This is a **specific
  question worth putting to whoever supplied the formulas**: does the standard/aquarium/octagon
  formula compute the *pre-discount* line price, with the invoice's own "Disc Rate" column applied
  afterward as a separate step — or is a discount already folded into one of the formula variants
  (e.g. is "Chop & Join... × 20%" *the* discount, applied instead of a separate disc-rate column)?
  The two "× 20%" appearances in the formula notes (Chop & Join wood, and Matt-cut store-supplied)
  are suspiciously close to the "20" seen in the Disc Rate column on several receipt lines — that
  may or may not be the same 20%, and conflating them without confirmation would be a guess.
